# AI for Product Managers - course decks (ACA X)

Public, rendered slide decks for the Armenian Code Academy "AI for Product Managers" course and its intro webinar. Built with a shared deck engine on the official ACA X design system (black + neon green, Barlow).

## Links
- Home: `/`
- Webinar: `/webinar/`
- Sessions: `/sessions/session-1/` through `/sessions/session-8/`

## Controls
Arrow keys or on-screen buttons to navigate, `F` for fullscreen, `#n` in the URL jumps to slide n.

## Notes
- This repo holds only the rendered decks. Speaker notes and source materials live in a separate private repo.
- Built with AI, the way the course teaches you to build.
